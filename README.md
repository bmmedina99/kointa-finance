# Kointa 💰

**Kointa** es una aplicación web para la **gestión de finanzas personales**, diseñada para ayudar a las personas a llevar un control claro y visual de sus ingresos, gastos y categorías.

---

## Objetivo

Ofrecer una herramienta clara, rápida y agradable para gestionar las finanzas personales sin la complejidad de las aplicaciones bancarias tradicionales.

## Tecnologías utilizadas

- **Frontend**: React, Tailwind CSS
- **Backend**: Next.js, Node.js
- **Base de datos**: PostgreSQL
